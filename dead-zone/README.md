horde escalates as you level, and it never ends.

## Play it

### ▶ [https://drsamonline.github.io/neon-games/dead-zone/](https://drsamonline.github.io/neon-games/dead-zone/)

Runs in any modern browser. Once loaded it installs as an offline app and keeps
working with no connection.

**Controls** — `WASD` move · `Shift` run · mouse look · `LMB` fire · `RMB` aim ·
`R` reload · `V` melee · `G` throw · `X` bullet time · `Tab` weapon wheel ·
`1`–`9` weapon slot · `F` interact · `M` map. Every key is rebindable in
Settings → Controls. Touch controls appear automatically on a phone or tablet.

## What's in it

An open world that generates forever in every direction — twelve biomes, enterable
buildings, drivable cars, a companion who fights beside you, grenades and molotovs,
a base you build out, boss zombies with weak points, four game modes, a 16-mission
campaign, and a shop that moves around the city.

It is built on the **[Neon Engine](https://github.com/drsamonline/neon-engine)**, where all
the source lives. This repository holds the playable build and the licence.
