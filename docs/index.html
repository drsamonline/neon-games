Why it feels like an arcade

Runs in your browser

Powered by WebGL in any modern browser — no download, no launcher, no store page.

No account, no backend

Nothing to sign up for and no server to call — your session stays entirely on your device.

Open world, both ways

Procedurally generated cities for survival and for patrol — the world keeps generating as you roam.

Every key rebindable

Mouse and keyboard or touch, and any binding can be changed in Settings → Controls.

Moddable content packs

Drop a plain script in mods/ and add one tag — no server, no build step. Packs are validated on load.

Both run offline

Once loaded, each installs as an offline app and keeps working with the network unplugged.

Support the work

Free forever, and it stays free

No company, no ads, no tracking, no paid tier. If it earned its keep, a contribution keeps the next cabinet coming — any amount, or none.
