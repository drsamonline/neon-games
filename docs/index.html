Get started

Just press play — or run it locally

You need nothing but a browser. Developers can clone and serve the games themselves.

The hosted games above are ready to go. If you want to run the source yourself, serve the game folder over HTTP — browsers block JavaScript modules on file://, so double-clicking index.html will sit on the loading screen.

This is exactly the guidance in each game's START-HERE.txt: serve over HTTP, then open the local URL. The game also installs as an offline app once loaded.

# clone the games git clone https://github.com/drsamonline/neon-games.git cd neon-games/dead-zone # or neon-police # serve over HTTP (any one of these) python3 -m http.server 8080 # or, without Python: npx serve . # then open http://localhost:8080

Questions

FAQ

The things people ask at the arcade door.

Do I need an account or to install anything? +

No. Both games run entirely in your browser with no install and no account — you just open the page and click play.

Is it really free? +

Yes. Both games are free to play under CC BY-NC-SA 4.0 — share, study, mod and fork them, but credit Dr. Sohil Momin, don't use them commercially, and pass the same terms on.

Does it work offline? +

Once loaded, yes — the games install as an offline app and keep working with the network unplugged. There is no backend involved.

What can I play it on? +

Any modern browser with WebGL, on desktop or phone. It works with mouse and keyboard or touch, and on phones you get an on-screen stick and buttons.

Can I change the controls? +

Yes — every key can be changed in Settings → Controls in each game.

Can I make my own content? +

Yes. A content pack is a plain script that registers itself — drop it in mods/, add one <script> tag, and it loads with no server and no build step. Packs are validated on load, so a malformed one is skipped rather than breaking the game.

What are the games built with? +

Both are built on the Neon Engine, which is MIT licensed separately so you can build your own commercial games with it.
